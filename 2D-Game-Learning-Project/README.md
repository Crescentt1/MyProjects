# 2D Key Hunt Game

A simple 2D game developed in Java as a learning project, following the first part of a YouTube tutorial series on building a 2D game from scratch.

## About

The game is a basic 2D adventure where the player explores the environment and collects keys.

This project was created to learn and practice the fundamentals of 2D game development, including game loops, player movement, collision detection, and game mechanics.

## Features

- 2D player movement
- Collision detection
- Key collection
- Basic game environment
- Simple game mechanics

## Technologies

- Java
- Object-Oriented Programming (OOP)

## Learning Goals

This project helped me practice:

- Game loops and game updates
- 2D coordinate systems
- Player movement
- Collision detection
- Object-oriented programming
- Basic game development concepts
