# A-ABB-02
In this project we aim to create an app that facilitates the use of artificial 
to aid in the improvement of UML class and state diagrams

## Description
The app “Smart UML” transforms UML state and class diagrams by sending a query to an LLM.
The query contains a diagram to analyse, the LLM will then send an improved version of it.
Both the query and the response can be saved in the log and the gallery respectively.
User can also add comments through writing/ speech-to-text/ image to text, which will be saved in the log.
The log will save all queries sent to the LLM, and the gallery can be used to save response images.


## Getting Started

### Dependencies
* Android 13+


### Installing

* Github: https://github.com/RUB-SE-LAB-2024/A-ABB-02

### Executing program

* select image from gallery or camera
* write comment (optional)
    * use speech-to-text by clicking the mic button (optional)
    * convert image to text (optional)
    * text can also be copied (optional)
* send query by clicking on Response, this will switch to the response tab
* response to the query will be displayed in a few seconds
* improved image will be displayed and can be clicked on for better view
* output is also displayed in PlantUML alongside improvement recommendations and performance and security suggestions
* query will be automatically saved in the log, sorted by date.
* user can open the app gallery by clicking on the gallery tab
* gallery collections can be customized based on the users wishes
* widgets can be added on the device home screen as shortcut to access the log and the gallery (optional)
