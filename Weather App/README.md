# Weather App

A simple weather application that allows users to enter a city name and view the current weather conditions for that location.

## Features

- Search for a city by name
- Display current weather information
- Show temperature and weather conditions
- Simple and user-friendly interface

## Technologies

- HTML
- CSS
- JavaScript
- Weather API

## Purpose

This project was created as a learning project to practice **HTML, CSS, JavaScript, and working with APIs**.
