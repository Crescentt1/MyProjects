# Library Management System

A simple library management system developed to practice **object-oriented programming** and basic software design concepts.

## Features

- Manage books and library users
- Support printed books and e-books
- Borrow and manage books
- Handle different types of borrowable items
- Basic library management functionality

## Project Structure

The project includes classes such as:

- `LibraryService`
- `Library`
- `User`
- `Book`
- `PrintedBook`
- `EBook`
- `Borrowable`
- `Main`

## Technologies

- Java
- Object-Oriented Programming (OOP)

## Purpose

This project was created as a practice project to develop my understanding of **object-oriented programming**, **classes**, **inheritance**, **interfaces**, and **basic software design**.
